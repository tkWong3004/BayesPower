# Manuscript and Supplementary Materials

This folder contains the manuscript and supplementary files used to reproduce the numerical results and application examples from the paper.

### Files

`BayesPower.pdf` : This PDF is the manuscript.

`BF_abs_error.rmd` : This file is used for reproducing the results about the performance of numerical integration.

`BF_simulation.rmd` : This file is used for evaluating the numerical methods using simulation.

`illustrative_examples.r`: This R file is used for reproducing the results in Section 5, Application, of the paper.

`Figure1.r`: This R file is used for reproducing Figure 1 in the manuscript.
